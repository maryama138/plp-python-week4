# PLP Python Week 4

This assignment practices Python functions, parameters, return values, and default parameters.

* `welcome.py` - Contains a `welcome()` function that returns a greeting message.
* `toolbox.py` - Contains the `double()`, `is_pass()`, and `greet()` functions.

The `greet()` function was the hardest to write because it uses a default parameter and must work with both the default greeting and a custom greeting.
